# GitHub Readme Stats
Use primarily for GitHub profile and repository README presentation when statistical cards add useful context.

Upstream: https://github.com/anuraghazra/github-readme-stats

## Rules
- Statistics should support the README narrative, not dominate it.
- Keep cards visually consistent with the surrounding README.
- Do not imply that vanity metrics equal project quality.
- Avoid excessive cards and visual clutter.
- Verify current card endpoints, parameters, deployment guidance, and limitations upstream before generating URLs or configuration.

Combine with Markdown Badges and Simple Icons for coherent GitHub documentation.
