# Rough.js Visuals
Use for approachable hand-drawn diagrams, frames, arrows, callouts, maps, cards, and illustration accents. Prefer it when polished geometric precision would feel too corporate or sterile.

Upstream: https://github.com/rough-stuff/rough

## Rules
- Keep sketchiness purposeful and readable.
- Use rough shapes as emphasis, not noise.
- Preserve adequate contrast and whitespace.
- For diagrams, establish hierarchy before adding sketch effects.
- Verify current Rough.js API and package instructions upstream before writing implementation code.

## Good combinations
Pair with Mermaid when a structured diagram needs a more human visual treatment, and with Fontsource for friendly editorial typography.
