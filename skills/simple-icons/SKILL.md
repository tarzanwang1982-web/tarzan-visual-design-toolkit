# Simple Icons
Use when a design needs recognizable logos/icons for technologies, platforms, services, brands, or developer tooling.

Upstream: https://github.com/simple-icons/simple-icons

## Rules
- Verify the exact icon slug/name upstream.
- Preserve recognizable brand geometry; do not distort icons.
- Use icons to aid scanning, not replace necessary labels.
- Keep icon sizing and visual weight consistent.
- Check brand/trademark guidance when relevant.
- Do not invent an icon when the upstream collection does not contain it.

Useful with Mermaid architecture diagrams, Markdown Badges, README design, dashboards, and technology-stack slides.
