# Markdown Badges
Use for README technology stacks, build/status references, tooling summaries, and compact metadata where badges improve scanning.

Upstream: https://github.com/Ileriayo/markdown-badges

## Rules
- Badges summarize; they do not replace explanatory text.
- Keep naming, casing, and icon usage consistent.
- Avoid badge walls. Include only information useful to the reader.
- Group badges by meaning when several are necessary.
- Verify current badge examples and destination URLs before producing final Markdown.

Combine with Simple Icons and GitHub Readme Stats for GitHub-facing presentation.
