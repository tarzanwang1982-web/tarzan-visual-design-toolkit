# Radix Colors
Use for UI palettes that need predictable backgrounds, surfaces, borders, hover/active states, text, and semantic accents.

Upstream: https://github.com/radix-ui/colors

## Rules
- Choose colors by functional role, not isolated appearance.
- Maintain contrast for text and controls.
- Define background, surface, border, solid, hover, active, and text roles consistently.
- Keep semantic colors such as danger/success/warning distinct from decorative accents.
- Verify current token names and package usage upstream before coding.

Combine with Radix Primitives or shadcn for application UI.
