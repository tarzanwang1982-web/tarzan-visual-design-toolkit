# Fontsource Typography
Use for web typography selection, self-hosted/open-source font workflows, font pairing, and typographic hierarchy.

Upstream: https://github.com/fontsource/fontsource

## Workflow
Choose typography from the project's visual DNA: audience, language coverage, tone, reading environment, density, and hierarchy. Define display, heading, body, label, and numeric roles before adding many weights.

## Rules
- Confirm font availability and language/glyph coverage.
- Prefer a small intentional weight/style set.
- Optimize readability before novelty.
- Avoid pairing typefaces that compete for attention.
- Verify current Fontsource package names and integration instructions upstream before coding.

For multilingual work, explicitly check Chinese/Japanese/Korean support rather than assuming a Latin font covers it.
